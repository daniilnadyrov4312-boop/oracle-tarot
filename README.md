# Оракул — библиотека значений Таро

Локальная страница без сборки: открывается двойным кликом по `index.html`.

## Что внутри

- **78 карт** — старшие арканы (0–XXI) и младшие (Жезлы, Кубки, Мечи, Пентакли).
  Значения сверены с печатной таблицей и даны **только для прямого положения (▲)**,
  перевёрнутые (▼) не используются.
- **Сканы колоды Уэйта** (Rider–Waite–Smith, 1909) у каждой карты — в списке и в раскладе.
  Картинки подгружаются с Wikimedia Commons; без интернета вместо них показываются
  гравированные символы масти, страница продолжает работать.
- **Выбор карт списком.** Отмечаете карты — справа сразу раскрываются значения,
  совет, масть и стихия. Порядок выбора сохраняется и нумеруется.
- **Позиции расклада.** Селектор «Позиции» подписывает карты по порядку:
  Прошлое · Настоящее · Будущее, Ситуация · Совет · Итог, пять карт, Кельтский крест.
- **Разбор расклада** (от 2 карт): «Общая картина» — сколько карт каждой масти и стихии
  с полосками, о чём говорит преобладание, сколько старших арканов, тон расклада,
  фигурные карты, тузы, повторяющиеся числа.
- **Справочник** — масти, стихии, числа и порядок чтения расклада.
- Поиск по названию, ключевым словам и тексту значений, фильтры по мастям.

## Как править значения

Все тексты лежат в `js/cards.js`:

```js
{
  rank: 5, name: 'Пятёрка Мечей', en: 'Five of Swords', tone: 'heavy',
  keywords: ['конфликт', 'споры', 'стресс', 'враждебность', 'ложь'],
  meaning: 'Конфликт и разногласия: споры, стресс, враждебность и ложь…',
  advice: 'Не ввязывайтесь в спор, который только отнимает силы.'
}
```

- `tone`: `light` — светлая, `neutral` — нейтральная, `heavy` — тяжёлая. Влияет на разбор расклада.
- Масти, стихии и числа — в начале файла (`suits`, `elements`, `numbers`).
- Интерфейс и логика — `js/app.js`, оформление — `css/style.css`.

## Картинки

Имена файлов заданы в `js/app.js` (`MAJOR_FILES`, `SUIT_FILES`): старшие —
`RWS_Tarot_00_Fool.jpg` … `RWS_Tarot_21_World.jpg`, младшие — `Wands01.jpg`,
`Cups01.jpg`, `Swords01.jpg`, `Pents01.jpg` и так далее до `14`.
Чтобы перейти на локальные сканы, положите их в `img/` и поменяйте `cardImage()`
на `'img/' + file + '.jpg'`.

## Быстрые ссылки

Можно открыть сразу с выбранным раскладом:

```
index.html#s=swords-5,cups-10,major-13
```

## Как открыть

Двойной клик по `index.html` (Chrome, Edge, Firefox, Safari). Шрифты подтягиваются
из Google Fonts, без интернета остаётся системный Georgia — вёрстка не ломается.
