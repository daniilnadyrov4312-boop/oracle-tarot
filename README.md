# Оракул — библиотека значений Таро

**Сайт:** https://daniilnadyrov4312-boop.github.io/oracle-tarot/  
**Репозиторий:** https://github.com/daniilnadyrov4312-boop/oracle-tarot

Локальная страница без сборки: открывается двойным кликом по `index.html`.
Обновить сайт на GitHub — запустить `publish.ps1` (или попросить агента).

## Что внутри

- **78 карт** — старшие арканы (0–XXI) и младшие (Жезлы, Кубки, Мечи, Пентакли).
  Значения сверены с печатной таблицей и даны **только для прямого положения (▲)**,
  перевёрнутые (▼) не используются.
- **Сканы колоды Уэйта** (Rider–Waite–Smith, 1909) у каждой карты — в списке и в раскладе.
  Картинки подгружаются с Wikimedia Commons; без интернета вместо них показываются
  гравированные символы масти, страница продолжает работать.
- **Выбор карт списком.** Отмечаете карты — справа сразу раскрываются значения,
  совет, масть и стихия. Порядок выбора сохраняется и нумеруется.
- **Позиции расклада.** Селектор «Позиции» подписывает карты по порядку:
  Прошлое · Настоящее · Будущее, Ситуация · Совет · Итог, пять карт, Кельтский крест.
- **Разбор расклада** (от 2 карт): «Общая картина» — сколько карт каждой масти и стихии
  с полосками, о чём говорит преобладание, чего в раскладе нет, сколько старших арканов,
  тон, фигурные карты, тузы, повторы.
- **Режим стола.** Настоящий стол с картами: шаблон задаёт стартовые позиции, но не
  ограничивает их число. Шаблоны: 3 карты «ситуация и дополнения», 3 карты
  «прошлое · настоящее · будущее», 5 карт, 9 карт (мысли · чувства · действия),
  неделя (пн–вс с датами), день (3 карты на дату), месяцы (по 3 карты, месяцы
  разделены и подписаны) и свободный стол.
  Карты можно перетаскивать, добавлять из поиска (нажатием или перетаскиванием из
  окна выбора), привязывать уточнения к любой карте (у одной карты их может быть
  несколько), добавлять отдельные позиции, менять подписи, заменять и удалять карты,
  выравнивать расклад. Уточнение можно перепривязать к другой карте — это отдельное
  действие «К другой». Трактовка идёт группами: основная карта + её уточнения.
  Общую картину можно смотреть с уточнениями или только по основным картам.
  Стол сохраняется между визитами, ссылкой можно поделиться (кнопка «Ссылка»).
- **Справочник** — масти, стихии и их взаимодействие, числа и числовые семьи, придворные
  ранги, сигнификатор, пустая масть, направление взглядов, повторы, четыре слоя чтения
  с разборами Суда и Колесницы.
- Поиск по названию, ключевым словам и тексту значений, фильтры по мастям.

Идеи и трактовки справочника — по книге Мэри К. Гри «21 способ толкования карт Таро»
(в пересказе из сохранённых заметок), значения карт сверены с печатной таблицей.

## Как править значения

Все тексты лежат в `js/cards.js`:

```js
{
  rank: 5, name: 'Пятёрка Мечей', en: 'Five of Swords', tone: 'heavy',
  keywords: ['конфликт', 'споры', 'стресс', 'враждебность', 'ложь'],
  meaning: 'Конфликт и разногласия: споры, стресс, враждебность и ложь…',
  advice: 'Не ввязывайтесь в спор, который только отнимает силы.'
}
```

- `tone`: `light` — светлая, `neutral` — нейтральная, `heavy` — тяжёлая. Влияет на разбор расклада.
- Масти, стихии и числа — в начале файла (`suits`, `elements`, `numbers`).
- Интерфейс и логика — `js/app.js`, оформление — `css/style.css`.

## Картинки

Имена файлов заданы в `js/app.js` (`MAJOR_FILES`, `SUIT_FILES`): старшие —
`RWS_Tarot_00_Fool.jpg` … `RWS_Tarot_21_World.jpg`, младшие — `Wands01.jpg`,
`Cups01.jpg`, `Swords01.jpg`, `Pents01.jpg` и так далее до `14`.
Чтобы перейти на локальные сканы, положите их в `img/` и поменяйте `cardImage()`
на `'img/' + file + '.jpg'`.

## Быстрые ссылки

Можно открыть сразу с выбранным раскладом:

```
index.html#s=swords-5,cups-10,major-13
```

Или сразу со столом и расставленными картами. Ссылку на стол делает кнопка «Ссылка» —
она кладёт в адрес сжатое состояние расклада:

```
index.html#tab=table&d=<состояние стола>
```

Старые ссылки тоже работают: `#tab=table&l=row3&t=major-2,major-1,swords-5`
(`l` — `row3`, `row5` или `grid9`, `t` — карты по порядку позиций).

## Файлы

- `index.html` — разметка страницы;
- `css/style.css` — оформление;
- `js/cards.js` — значения 78 карт;
- `js/reference.js` — справочник: числа, придворные, стихии, слои, сигнификатор;
- `js/app.js` — библиотека карт, панель значений, справочник;
- `js/board.js` — режим стола: шаблоны, перетаскивание, уточнения, сохранение и ссылки;
- `publish.ps1` — публикация на GitHub Pages.

## Как открыть

Двойной клик по `index.html` (Chrome, Edge, Firefox, Safari). Шрифты подтягиваются
из Google Fonts, без интернета остаётся системный Georgia — вёрстка не ломается.
